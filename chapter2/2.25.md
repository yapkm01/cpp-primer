Exercise 2.25:
Determine the types and values of each of the following
variables.

	(a) int* ip, &r = ip;		(b) int i, *ip = 0;		(c) int* ip, ip2;

(a)
	ip a pointer to int; uninitialized
	r is reference to an int pointer
(b)
	i is an int; uninitialized
	ip is a pointer to an int and initialized to null or 0
(c)
	ip is a pointer to int and uninitialized
	ip2 is an int and uninitialized
