Exercise 2.29:
Using the variables in the previous exercise, which of the
following assignments are legal? Explain why.

	(a) i = ic;		(b) p1 = p3;
	(c) p1 = &ic;	(d) p3 = &ic;
	(e) p2 = p1;	(f) ic = *p3;

(a) i = ic;     // legal
(b) p1 = p3;    // legal. can change address stored in p1
(c) p1 = &ic;   // legal. can change address stored in p1
(d) p3 = &ic;   // illegal. p3 is a const pointer to a const int which cannot have its address modified
(e) p2 = p1;    // illegal. p2 is a const pointer which cannot have its address modified
(f) ic = *p3;   // illegal. ic is a const int
